# Motion Beyond Pixels: Learning Future Visual Representations for Object-Centric Dynamics

This repository hosts the project page for **MotionRep**, served via GitHub Pages.

Once Pages is enabled for this repository, the page will be live at:
`https://<github-username>.github.io/<repository-name>/`

## Local preview

The page is fully static and self-contained (no external network requests, including fonts). To preview it locally:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
